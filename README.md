# Greek-Regions-for-WooCommerce
Το plugin “Greek Regions for WooCommerce” επεκτείνει το WooCommerce προσθέτοντας και τους 51 νομούς της Ελλάδας στη διαδικασία checkout.

## Περιγραφή
Το plugin "Greek Regions for WooCommerce" επεκτείνει το WooCommerce προσθέτοντας και τους 51 νομούς της Ελλάδας στη διαδικασία checkout.

Μετά την εγκατάσταση και ενεργοποίηση του plugin, όλοι οι νομοί της Ελλάδας θα είναι διαθέσιμοι αυτόματα στο dropdown menu της περιοχής/νομού όταν επιλέγεται η "Ελλάδα" ως χώρα.

Χαρακτηριστικά
* Προσθέτει και τους 51 νομούς της Ελλάδας στο WooCommerce
* Εμφανίζεται αυτόματα στη διαδικασία checkout
* Αλλάζει την ετικέτα "State/County" σε "Νομός" όταν επιλέγεται η Ελλάδα
* Πλήρως μεταφρασμένο με ελληνικούς χαρακτήρες
* Δεν απαιτείται ρύθμιση - λειτουργεί αμέσως
* Συμβατό με τις τελευταίες εκδόσεις WordPress και WooCommerce

Πλεονεκτήματα
* Βελτιώνει την εμπειρία χρήστη για Έλληνες πελάτες
* Επιτρέπει την ακριβή καταγραφή της περιοχής παράδοσης
* Βοηθά στην οργάνωση των παραγγελιών ανά γεωγραφική περιοχή
* Υποστηρίζει τόσο τη διεύθυνση χρέωσης όσο και τη διεύθυνση αποστολής

Απαιτήσεις
* WordPress 5.0 ή νεότερη έκδοση
* WooCommerce 3.0.0 ή νεότερη έκδοση
* PHP 7.2 ή νεότερη έκδοση

## Installation

1. Ανεβάστε τα αρχεία του plugin στον κατάλογο `/wp-content/plugins/greek-regions-woocommerce`, ή εγκαταστήστε το plugin απευθείας μέσω του WordPress plugin installer.
2. Ενεργοποιήστε το plugin από το μενού 'Πρόσθετα' στο WordPress.
3. Δεν απαιτείται καμία επιπλέον ρύθμιση - οι ελληνικοί νομοί θα εμφανίζονται αυτόματα όταν επιλέγεται η Ελλάδα ως χώρα στο checkout του WooCommerce.
